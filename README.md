# Japan Travel Buddy – POI-Fotos

Bildsammlung für die App Japan Travel Buddy (nicht-kommerziell). Die Fotos stammen aus
Wikimedia Commons, Pixabay und Unsplash. Je Foto stehen Urheber, Quelle und Lizenz in
`credits.json`; die Urheberangabe wird in der App am Foto angezeigt. Die Bilder wurden
auf 4:3 zugeschnitten und verkleinert (1280x960). Lizenzen der Originale gelten unverändert
(z. B. CC BY-SA bei Commons).
